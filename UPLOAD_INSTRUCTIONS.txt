GITHUB UPLOAD AND PAGES SETUP

1. Open or create:
   https://github.com/SyedRaheelShahzad/syed-raheel-shahzad

2. Upload every file and folder from this package to the repository root.
   Do not upload the outer package folder itself.

3. Preserve these exact Unicode folder names:
   ar-سيد-راحيل-شهزاد
   ur-سید-راحیل-شہزاد
   hi-सैयद-राहील-शहज़ाद

4. Commit to the main branch.

5. Open Repository Settings > Pages.

6. Choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
